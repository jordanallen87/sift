# Sift Brand Asset Kit

## Direction

Sift uses the approved **S symbol + IFT** lockup. The symbol represents information being sifted down into a useful signal. This export is intentionally flat: **no gradients, glows, shadows, purple/blue AI palette, or secondary accent colors**.

## Palette

Primary: `#1F5C52`. Supporting colors are only lighter/darker values of the same green plus neutral black/gray/white.

## Logo use

- `logo-horizontal-primary.svg`: green symbol with subtle green-only particle variation + neutral IFT.
- `logo-horizontal-green.svg`: one-color green mark for simple brand use.
- `logo-horizontal-black.svg` / `white.svg`: strict monochrome.
- `symbol-primary.svg`: green-family symbol without the IFT lockup.
- App icons use a flat Sift Green square with a white symbol.

## Clear space

Keep at least the width of the `I` stem around the horizontal logo. Do not place the mark against a visually noisy background unless using a solid container.

## Small sizes

Use the one-color `symbol-green.svg` or app icon below ~48px. The decorative sift particles can become visually dense at favicon scale. Use the `*-simple-*` app-icon exports and `symbol-core-*` masters below ~64px; the supplied favicon files already use this simplified mark.

## Typography

The supplied `IFT` is outlined/vector artwork extracted from the approved lockup, so **no font file is required** to render the logo correctly. Product UI typography should stay modern and neutral; Geist, Inter, or a similar grotesk is a good fit, but the logo does not depend on one.
